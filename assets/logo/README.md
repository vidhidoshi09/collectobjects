# collectobjects logo

Brand files for the Play Store and anywhere else. Not bundled into the app (see `scripts/build-web.js`).

| File | Use |
|---|---|
| `icon-512.png` | Play Store app icon (512×512, full square: Play applies its own mask) |
| `icon-1024.png` / `icon.svg` | The icon at large size / as vector |
| `icon-1024-rounded.png` | The icon with rounded corners, for decks and the web |
| `mark-white.png` / `mark-white.svg` | The "co" line alone, paper white on transparent, for dark or coloured backgrounds |

Colours: burgundy `#8E1B2D`, orange `#F5A742`, paper `#FAF9F7`. The Android launcher icons live in `android/app/src/main/res/mipmap-*`.
